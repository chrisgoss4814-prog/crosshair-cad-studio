# 3D Space Weaver

I want to create an app that is like a video game but I want to use it as a cad software. I want to have a thin Cross hair in the center of the screen and I wany to be able to move the cross hair through 3d space. I want an x y and z axis. I want to be able to place 3d objects on the 3d place that the cross hair is located at the moment I press an add button. I want to move around by using two digital joysticks where one moves left right forward and back and the other moves in a spin motion where it pivot at a point in any direction
